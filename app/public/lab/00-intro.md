# Introduction

Welcome! This is a **fully simulated** lab. Every command you type in the
terminal on the right is scripted by the lab author and runs entirely in your
browser — there is no real Docker daemon, server, or network.

That means the lab works the same way for everyone, every time, with nothing to
install.

::variableDefinition[containerName]{prompt="What should we name the container?"}

Your container will be named **$$containerName$$**.

When you're ready, head to the next section to run a container.
