---

## Things worth remembering

- An **image** is built once and run anywhere
- A **container** is disposable; treat it that way
- If it isn't in the **Dockerfile**, it isn't in the image

Note: Last slide. Leave it up during the hands-on portion — it's a useful
reference while people work, and it saves you repeating the three points.
